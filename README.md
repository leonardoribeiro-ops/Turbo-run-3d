# 🏎️ Turbo Run 3D

## Sobre o projeto

O **Turbo Run 3D** é um jogo de corrida de carros em 3D desenvolvido como projeto escolar. O objetivo é controlar um carro, desviar dos obstáculos, coletar moedas e chegar até a linha de chegada.

O jogo possui um visual inspirado em corridas futuristas, com cores neon e uma pista em três dimensões.


https://leonardoribeiro-ops.github.io/Turbo-run-3d/

## 🎮 Funcionalidades

- Garagem com quatro opções de cores para o carro: azul, vermelho, preto e verde.
- Corrida em uma pista 3D.
- Controle do veículo pelo teclado.
- Obstáculos espalhados pela pista.
- Sistema de colisões que causa danos ao carro.
- Barra que mostra a integridade do veículo.
- Marcas visuais que aparecem conforme o carro sofre danos.
- Efeito de fumaça quando o veículo está muito danificado.
- Moedas para coletar durante a corrida.
- Sistema de pontuação.
- Linha de chegada.
- Tela de finalização e opção para jogar novamente.

## 🕹️ Controles

| Tecla | Função |
|---|---|
| ← | Mover para a esquerda |
| → | Mover para a direita |
| ↑ | Acelerar |
| ↓ | Frear |

**Atenção:** bater nos obstáculos reduz a integridade do carro. Se ela chegar a zero, a corrida termina.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da página e dos elementos do jogo.
- **CSS3:** aparência, cores, painéis e organização da interface.
- **JavaScript:** movimentação do carro, pontuação, moedas, colisões e funcionamento do jogo.
- **Three.js:** criação dos objetos, da pista e do ambiente em 3D.
- **Git e GitLab:** armazenamento e organização dos arquivos do projeto.

## ▶️ Como executar o jogo

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Confira se os arquivos estão nas pastas corretas.
4. Instale a extensão Live Server, caso ainda não tenha.
5. Clique com o botão direito no arquivo `index.html`.
6. Selecione **Open with Live Server**.
7. O jogo será aberto no navegador.

É necessário ter conexão com a internet para carregar a biblioteca Three.js pelo CDN utilizado no projeto.

## 🤖 Utilização da Inteligência Artificial

A Inteligência Artificial foi utilizada como ferramenta de apoio durante o desenvolvimento do projeto.

Ela ajudou com:
- Criação e organização de partes do código.
- Desenvolvimento dos elementos em 3D.
- Implementação dos controles do carro.
- Criação do sistema de pontuação e moedas.
- Implementação das colisões e dos danos no veículo.
- Correção de erros e melhorias no visual.

Os pedidos foram feitos por meio de prompts, explicando as funcionalidades desejadas para o jogo.

**Exemplos de prompts utilizados:**

- "Crie um jogo de corrida 3D utilizando HTML, CSS, JavaScript e Three.js."
- "Adicione obstáculos, moedas e uma linha de chegada."
- "Faça com que o carro sofra danos quando bater nos obstáculos."
- "Adicione uma garagem para escolher entre diferentes cores de carros."

A IA foi utilizada como apoio, enquanto o projeto foi testado e ajustado durante o desenvolvimento.
