# Turbo Run 3D

Jogo de corrida 3D para navegador, feito com HTML, CSS, JavaScript e Three.js.

## Como executar
1. Abra a pasta `turbo-run-3d` no Visual Studio Code.
2. Instale a extensão Live Server, se ainda não tiver.
3. Clique com o botão direito em `index.html` e escolha **Open with Live Server**.
4. Mantenha a internet conectada porque o Three.js é carregado por CDN.

## Controles
- Seta para esquerda: mover o carro para a esquerda.
- Seta para direita: mover o carro para a direita.
- Seta para cima: acelerar.
- Seta para baixo: frear.
- O objetivo é chegar à linha de chegada; as moedas valem 10 pontos.

## Arquivos
- `index.html`: estrutura da página.
- `css/style.css`: visual e interface.
- `js/script.js`: lógica e cena 3D.
- `GDD/GDD_Turbo_Run_3D.docx`: documentação do jogo.
- `assets/Turbo_Run_3D_Capa.png`: imagem de capa.

## Publicar no GitLab
1. Crie um projeto chamado `turbo-run-3d` no GitLab.
2. Envie todos os arquivos desta pasta para o repositório.
3. Configure o GitLab Pages para publicar o site estático seguindo as instruções atuais do GitLab.
4. Abra o endereço público em uma janela anônima para testar.

Antes da entrega, teste todos os controles e confirme que o jogo termina ao cruzar a linha de chegada.
